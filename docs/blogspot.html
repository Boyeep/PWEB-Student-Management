Pada tugas Pemrograman Web kali ini, saya membuat CSS UI Student Management menggunakan HTML, CSS, dan JavaScript. Website ini menyediakan form mahasiswa serta tabel data dengan tampilan yang rapi, responsif, dan mudah digunakan.

Fokus latihan ini adalah mengatur layout, warna, tipografi, form, tabel, tombol, dan responsive design dengan CSS. JavaScript ditambahkan agar proses menambah, mengedit, menghapus, dan mencari data mahasiswa dapat dicoba secara langsung.

Tujuan Latihan

  • Menyusun antarmuka Student Management menggunakan HTML semantik.
  • Menerapkan CSS Grid dan Flexbox untuk mengatur layout.
  • Membuat komponen form, tabel, tombol, dan pagination yang konsisten.
  • Menggunakan media query agar tampilan dapat menyesuaikan ukuran layar.
  • Menambahkan interaksi pengelolaan data mahasiswa dengan JavaScript.

Konsep Tampilan

Tampilan menggunakan navbar biru tua, latar belakang abu-abu muda, dan kartu putih untuk memisahkan bagian form dan data mahasiswa. Warna biru digunakan untuk aksi utama, sedangkan warna merah digunakan pada aksi hapus.

Bagian atas menampilkan ringkasan total mahasiswa, jumlah jurusan yang terwakili, dan jumlah hasil pencarian. Pada desktop, form ditempatkan di kiri dan tabel di kanan. Pada layar kecil, kedua bagian ditampilkan dalam satu kolom.

Implementasi CSS

1. CSS Variables

Warna utama, latar belakang, teks, dan sudut komponen disimpan melalui CSS custom properties. Dengan cara ini, perubahan tampilan dapat dilakukan dari satu tempat.

:root {
  --primary: #245df2;
  --navy: #132b4b;
  --background: #f4f7fb;
  --surface: #ffffff;
  --text: #1c2d45;
  --border: #e2e8f1;
  --radius: 16px;
}

2. Layout dengan CSS Grid

CSS Grid membagi area utama menjadi kolom form berukuran 320 piksel dan kolom tabel yang menggunakan sisa ruang. Penggunaan minmax(0, 1fr) membantu membatasi kolom agar tabel tidak mendorong lebar halaman.

.workspace {
  display: grid;
  grid-template-columns: 320px minmax(0, 1fr);
  align-items: start;
  gap: 24px;
}

3. Navbar dan Toolbar dengan Flexbox

Flexbox digunakan untuk menyusun identitas aplikasi dan navigasi pada header. Pendekatan yang sama digunakan pada toolbar pencarian agar kolom pencarian dan filter jurusan berada dalam satu baris di desktop.

.header-inner {
  min-height: 78px;
  display: flex;
  align-items: center;
  gap: 38px;
}

.table-toolbar {
  display: flex;
  gap: 12px;
  margin: 24px 26px;
}

4. Form dan Focus State

Setiap input memiliki label, jarak yang konsisten, dan penanda kolom wajib. Saat input dipilih, warna border berubah menjadi biru dengan bayangan tipis sehingga posisi fokus lebih mudah dikenali.

.field input:focus,
.field select:focus {
  border-color: var(--primary);
  outline: 0;
  box-shadow: 0 0 0 3px rgb(36 93 242 / 12%);
}

:focus-visible {
  outline: 3px solid var(--primary);
  outline-offset: 3px;
}

5. Tabel dan Tombol Aksi

Header tabel menggunakan latar yang berbeda dari baris data. Setiap baris memiliki garis pemisah, hover state, badge jurusan, dan tombol edit serta hapus. Tabel ditempatkan di dalam wadah yang dapat digulir secara horizontal pada layar kecil.

.table-scroll {
  width: 100%;
  overflow-x: auto;
}

table {
  width: 100%;
  min-width: 810px;
  border-collapse: collapse;
  text-align: left;
}

tbody tr:hover {
  background: #f8faff;
}

6. Responsive Design

Pada lebar maksimal 980 piksel, layout utama berubah menjadi satu kolom. Pada lebar maksimal 640 piksel, form, toolbar, dan susunan tombol disesuaikan lagi agar tetap nyaman digunakan pada ponsel.

@media (max-width: 980px) {
  .workspace {
    grid-template-columns: minmax(0, 1fr);
    gap: 22px;
  }
}

@media (max-width: 640px) {
  .form-card form {
    display: block;
  }

  .table-toolbar {
    flex-direction: column;
  }
}

Fitur Website

  1. Form mahasiswa: input NIM, nama lengkap, jurusan, dan email.
  2. Tambah mahasiswa: data valid masuk ke tabel dan ringkasan jumlah mahasiswa diperbarui.
  3. Edit mahasiswa: data baris yang dipilih dimuat ke form untuk diperbarui.
  4. Hapus mahasiswa: penghapusan dilakukan setelah konfirmasi pada dialog.
  5. Batal dan reset: batal mengakhiri pengisian atau mode edit; reset mengosongkan kolom sambil mempertahankan mode yang sedang digunakan.
  6. Pencarian: mencari mahasiswa berdasarkan nama, NIM, jurusan, atau email tanpa membedakan huruf besar dan kecil.
  7. Filter jurusan: membatasi hasil berdasarkan program studi dan dapat digunakan bersama pencarian.
  8. Pagination: menampilkan lima mahasiswa per halaman dengan informasi rentang data.
  9. Penyimpanan lokal: perubahan data disimpan melalui localStorage agar tetap tersedia setelah refresh pada browser yang sama.

Data awal berisi 12 mahasiswa fiktif dari empat jurusan. Website ini merupakan latihan frontend. Penyimpanan berlaku pada browser dan perangkat yang digunakan, tanpa backend atau sinkronisasi antarpengguna.

Pengujian

Pengujian dilakukan menggunakan Chrome dalam mode headless. Seluruh 13 kelompok pemeriksaan lolos dan tidak ditemukan error JavaScript selama pemeriksaan.

  • Tambah, edit, hapus, batal, dan reset data mahasiswa.
  • Validasi kolom wajib, format email, nama kosong, dan NIM duplikat.
  • Pencarian, filter jurusan, pagination, dan tampilan ketika tidak ada hasil.
  • Penyimpanan setelah refresh serta penanganan data tersimpan yang rusak atau kosong.
  • Tampilan pada lebar 375, 768, 812 dalam orientasi landscape, 1366, dan 1600 piksel.
  • Navigasi keyboard, dialog, dan preferensi reduced motion.

Detail pemeriksaan tersedia pada laporan pengujian project.

Cara Menjalankan

Website dapat dijalankan dengan membuka index.html di browser modern. Alternatifnya, jalankan perintah berikut dari folder project untuk menggunakan server lokal:

python -m http.server 8000

Setelah itu, buka http://localhost:8000. Project tidak memerlukan proses build atau instalasi package untuk digunakan.
