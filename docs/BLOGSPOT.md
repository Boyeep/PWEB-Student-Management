# Artikel siap upload ke Blogspot

**Judul postingan:** Tugas Pemrograman Web: CSS UI Student Management

**Label yang dapat digunakan:** Pemrograman Web, HTML, CSS, JavaScript, Student Management

1. Buka file `blogspot.html` dalam editor teks.
2. Salin seluruh isi file tersebut.
3. Buat postingan baru di Blogger dan masukkan judul di atas.
4. Ubah editor postingan ke mode **Tampilan HTML**, lalu tempel isi file.
5. Gunakan Preview untuk mengecek tampilan sebelum menerbitkan postingan.

Artikel sudah menyertakan screenshot dari repository GitHub, tautan source code, dan tautan demo. Seluruh teks artikel bebas dari em dash. File merupakan isi artikel, sehingga tidak perlu menambahkan tag `html`, `head`, atau `body`.
