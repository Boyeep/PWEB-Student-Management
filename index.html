Student Management

Project latihan HTML, CSS, dan JavaScript untuk mengelola daftar mahasiswa melalui form, tabel, pencarian, filter jurusan, dan pagination.

Seluruh data awal bersifat fiktif. Perubahan tersimpan pada browser dan perangkat yang digunakan, sehingga tidak dibagikan ke pengguna lain.
